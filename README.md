# Weather App

A clean, responsive weather application built with vanilla JavaScript. It fetches real-time weather data and a 7-day forecast using the Open-Meteo API.

## Features

- **City Search:** Look up current weather for any city worldwide.
- **Current Conditions:** View temperature, "feels like", humidity, UV index, and sunrise/sunset times.
- **7-Day Forecast:** Plan ahead with a weekly weather breakdown.
- **Unit Toggle:** Switch seamlessly between Celsius (°C) and Fahrenheit (°F).
- **Dark / Light Mode:** Theme toggle for comfortable viewing.
- **Live Clock:** Real-time updating time and date display.

## Tech Stack

- **HTML5 & CSS3**
- **Vanilla JavaScript (ES6+)**
- [Open-Meteo API](https://open-meteo.com/) (Weather data & Geocoding)
